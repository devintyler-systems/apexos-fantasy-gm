# League Rules Contract Changelog

## spamml-2026-v0.2 — 2026-08-09
**Confirmed in this version:**
- REC1/2/3 slots accept both WR and TE (confirmed)
- RB slots are HB/FB only; no flex
- D/O slot is one full NFL team (offense + defense + special teams); team-level only
- D/O scores: defensive TDs (6), safeties (2), ST TDs (6) — kicker PAT/FG do NOT score in D/O slot
- Weekly $10 prizes for top offense and top defense are separate from fantasy scoring
- Single team can sweep both weekly prizes
- Draft format is non-standard snake (confirmed from 2025 pick history)
  - Rounds 1–2 and 5–6: standard snake
  - Rounds 3–4 and 7–8: pivot starting from team 9 position
- Platform: custom manual site (primary) + Fantrax mirror (personal tracking)
- No API sync available; all draft state is manual entry
- Add/drop transaction cost: $10 each
- No bench; 8 total starters
